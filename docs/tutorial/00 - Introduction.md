# Philosophy
## Paradigm
caret is a imperative language which means caret doesn't have classes. Also, the language doesn't have traits or interfaces like Rust and Golang. With this design choice, caret follows very close approach to the C language.

## Minimalism

Minimalisim is very important aspect for caret. ***The language aims to provide one obvious way to accomplish any given task.***
